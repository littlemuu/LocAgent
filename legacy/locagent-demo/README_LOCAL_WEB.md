# 本地浏览器工作台

当前主入口见 [README](README.md)。工作流：浏览器输入仓库与问题 → 免费准备 → 审阅固定计划 → 明确确认一次运行 → 查看源码证据、工具轨迹和用量。

## 启动与免费演示

先在项目根目录按主 README 安装 `.venv`：

```sh
./start-local-web.command
# 若原来的 8765 服务还在，用独立端口，勿停止它：
./start-local-web.command --port 8766
```

默认仅监听 `127.0.0.1`，数据目录为本副本 `web-runs`，付费关闭；打开输出的本机地址。也可设置 `LOCAGENT_PYTHON` 指定已安装依赖的 Python。脚本没有任何开发者电脑的绝对路径兜底。

无供应商配置也能点击「免费演示」。它展示固定合成结果，不能拿它宣称真实定位成功。

## 准备真实公开仓库

1. `cp locagent_service/local_provider.example.json provider.local.json`。
2. 用本地编辑器核实并填写供应商 endpoint、真实模型/响应模型、上下文上限、全包最高价格、币种与本题预算。示例中的 `REPLACE...` 和 `context_tokens=0` 故意不可执行。不填 key。
3. 重启本副本服务，输入公开 GitHub Python 仓库链接、问题和可选 ref，点击「免费准备」。
4. 审阅固定 commit、完整问题、接收方、费用上限、单次预留、最大请求次数和计划 SHA256。

准备只联系 GitHub，不把问题发给模型。使用图/BM25，不提供 dense/hybrid。配置改变要重启并重新准备；不要复用旧计划或历史授权。详细参数和费用解释见 [CLI 手册](README_LOCAL_CLI.md)。

## 真实模型运行是另一个明确动作

页面右上角的「配置 API Key」会展示本机设置步骤和可复制的无密钥命令。网页不接收密钥，也不提供启动终端或执行 shell 的 HTTP 接口。普通浏览器无法直接打开 Terminal，因此需要在本机操作一次。

1. 先完成 `provider.local.json`（不填 key）。DeepSeek 用户可复制项目根目录的 `provider.deepseek.reference.json` 为该文件，避免从头填写。它是 2026-11-07 旧配置的无密钥参考：`deepseek-flash`、1,048,576 上下文、输入/输出 CNY 2/8 每百万 token、预算 CNY 2.20、最多 3 次请求。**这些不是当前价格或预算授权**。先核实 [官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 与账户情况，调整模型、价格、上下文及自己选择的预算，再将 `pricing_confirmation` 的整段 `REPLACE...` 替换为实际核实日期和来源。模板带有拒绝启动的标记，不会误用旧价启用模型。其他供应商仍使用原示例配置。
2. 等待当前任务结束，在本副本启动终端 Ctrl-C 停止旧服务。
3. 在项目目录运行下列命令，或在 Finder 双击 `configure-api-key.command`。其他端口请添加 `--port 8766`；页面命令会使用当前地址的端口。

```sh
./start-local-web.command --prompt-api-key --enable-paid-run
```

核实终端显示的接收方，再隐藏输入 API Key。空输入或 Ctrl-C 取消；非交互终端或无法禁用回显时拒绝输入。密钥只进入当前服务进程和经明确授权的运行子进程环境，不写配置、shell 历史、浏览器或日志，也不会设置父 shell 的环境变量。关闭服务后需重新输入，内存并非防恶意本机进程的保险箱，不要在不可信共享电脑上使用。

若此前已有 shell 环境变量方式，仍可继续使用原来的 `--enable-paid-run`。新开终端中的环境变量不会自动进入已运行服务；两种方式都需要重启。刷新页面不会重启服务。更换供应商配置后重新免费准备，不复用旧计划。

启用开关和输入密钥本身不调用模型。页面仍需逐题同意精确计划，才向已核实供应商发送问题、代码片段、图/工具输出和对话历史，key 作为该 endpoint 的认证头。

单次完整预留 = `(context_tokens × input_per_million + output_tokens × output_per_million) / 1,000,000`。全部调用预留之和不是实际预扣，也不会提高总预算。未知状态保留预留并停止。

## 状态与停止

- 浏览器仅保存任务编号。刷新、后退、重新查看不会重新运行。
- “换个问题”只切换页面，不重放旧任务；关闭网页不取消后台请求。
- 在本次启动终端 Ctrl-C 正常停止。已经发送的请求仍可能收费。
- 同题重复点击、网络响应丢失、超时均不自动重放。
- 崩溃重启遇到旧活动任务，会进入只读检查。先确认旧进程和账单，不删除标记。另开数据目录也不等于获得重试旧题的授权。

`web-runs/<id>/` 含问题、源码、结果、计划与账本，不能整体公开。网页不提供任意文件读取、key 或原始授权文件下载。

## 证据和边界

`success` 是合法完成，不等于命中率。两次后续真实案例见 [实测摘要](docs/REAL_CASES.md)；这不是旧合成预览。当前整理测试见 [当前验证](docs/DEMO_VALIDATION.md)，历史 UI 验收见 [LOCAL_WEB_SIMPLIFIED_UI](docs/LOCAL_WEB_SIMPLIFIED_UI.md)。

服务有 Host/Origin/session 校验、CSP、纯文本结果与单活动任务限制。它仍然不是完整 OS 沙箱或多用户产品，macOS 不提供可靠地址空间限额，亦无总磁盘配额。不得绑定公网或当作不可信多人服务。

## 逐次模型调用用量

任务进度下方的「模型调用 · Token 与费用」展示每次调用的输入/输出 token、状态和估算费用，运行中也随状态查询更新。数据来自现有账本；尚未收到或未通过核验的用量显示未知，不当作 0。合计仅含已知记录，未结算的预算预留单独显示，预留不代表扣费。

Token 是服务商返回值；费用沿用本次计划配置的输入/输出单价，输入全部按配置输入价估算，未单独扣除缓存优惠，不是服务商实际账单。免费示例明确为 0 次真实调用；旧任务缺少逐次记录时不反推。

本次仅更新静态页面，现有服务按请求读取静态文件，刷新页面即可，无需重启或重新输入 key。查看历史任务不会重跑模型。

## 易读查找过程

结果区域的「查找过程 · 一步步看」按已保存的 assistant 回复分轮展示模型请求的工具、请求参数和按 tool_call_id 匹配的工具返回。参数、模型可见回复与工具正文可展开，分页输出标注已读取范围；finish 单独说明是结束声明，不伪造执行返回。这不是模型内部思维链。回复顺序不自动映射计费账本序号，未保存或失败的调用可能没有回复。

旧任务缺少 messages 时明确提示无法还原，不用 return_records 反推调用顺序；重复或缺失 ID 不猜测匹配。保留「查看 JSON 技术详情」，仅显示筛选后的可见记录与结果摘要，排除原始系统/用户提示词、诊断与隐藏推理字段，过滤常见凭据、邮箱、用户目录等。自动过滤不能保证覆盖所有私人内容，请勿直接公开分享。本机原始文件未修改。

只改静态资源，刷新现有页面即可；无需重启、重新输入 key 或重跑模型。离线校验：ChatGPT 自带 Node 执行 `--check locagent_service/local_web_assets/app.js` 和 `--test tests/local_web_ui.test.cjs`。
