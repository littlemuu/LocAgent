在本机终端配置 API Key

正在读取配置状态…

密钥不要贴到网页或聊天中。浏览器不会直接打开终端，请按以下步骤操作：

  1. 先确认没有任务正在准备或运行，再回到启动此服务的终端按 Ctrl-C 停止。不要停止其他端口的服务。
  2. 如果尚未配置供应商，使用 DeepSeek 时，在项目文件夹复制 provider.deepseek.reference.json 为 provider.local.json。参考值来自 11 月 7 日旧配置，不能视作当前价格或付费授权。先核实官方当前模型、上下文和账户价格，选择自己的预算，更新字段及 pricing_confirmation（替换 REPLACE 开头的整段文字为核实日期与来源）。这个文件不填密钥；未核实的模板无法启动。其他供应商请使用 locagent_service/local_provider.example.json。
  3. 在同一个项目终端粘贴下面的命令，或在 Finder 中双击项目里的 configure-api-key.command（默认端口 8765，其他端口请用下方命令）。
  4. 终端会显示接收方地址。核实后输入 API Key 并回车，输入时不会显示字符；直接回车或 Ctrl-C 可取消。
  5. 看到服务地址后刷新此页面。配置或更换供应商后，请重新免费准备任务并确认新的费用计划。
./start-local-web.command --prompt-api-key --enable-paid-run

密钥仅留在本次服务及明确授权的模型请求进程中，不保存到文件、浏览器或 shell 历史。重启需重新输入。启用入口不会调用模型，仍需逐题确认付费；实际调用时密钥会作为认证信息发送给你核实的供应商。不要在不信任的共享电脑上使用。
