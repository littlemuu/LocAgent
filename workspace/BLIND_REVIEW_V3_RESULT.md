# 六题回答盲化 AI 评审结果

2026-11-12。完成十二份回答、每份四项冻结标准的质量评审。两位全新上下文评审各独立完成 48 项二元评分，47 项一致（97.9%）；唯一分歧由第三位全新上下文评审独立裁决。所有评分文件先保存并固定 SHA256，之后才读取组别映射、解盲汇总。无评审失败，无新增外部模型 API 调用。

这是**盲化条件下的 AI 复核**，不是独立人类盲评，也不能保证完全消除组别推断。原始运行结果、源码、评分标准、账本和费用未改写。

## 掩蔽与流程

此前匿名包的顺序可能泄露题目/组别。此次重新生成随机编号，给 A、B 各自独立打乱顺序；评审材料只包含问题、完整答案、固定源码和四条原标准，不含旧标签、运行顺序、模型/工具轨迹、耗时、费用或组别映射。全部 36 个源码文件按冻结 hash 核验后复制，答案和标准原文不变。

两位评审以不继承此前对话的全新上下文启动，分别只允许读取自己的包和源码。正文检查未发现 LocAgent、baseline、retrieval、read_file 等显式工具或组别名称；评审也均报告未发现分组信息、未接触映射或另一评审结果。问题本身保留，所以可以辨认题目，但不能据此直接确定两个答案的组别。

评审前书面固定二元解释：一条复合标准的实质要求全部被正确表达才得 1 分，允许等价表达；不从源码替答案补足遗漏，不新增评分项；额外不实推断单独记录。评分前也固定分歧规则：一致项保持原分；分歧项交第三人，不提供前两人的分数或理由，按三票多数决定。

主线程此前看过原答案和结果，因此仅组织材料、校验和汇总，没有参与或更改评分。第三位评审同样使用全新上下文，仅收到争议答案、原标准和源码。

## 解盲结果

每题满分 4 分，每组满分 24 分；“检索组”表示额外开放 LocAgent，并不表示每题都使用了它。

| 题目 | 基础组 | 检索工具可用组 | 主要扣分点 |
| --- | ---: | ---: | --- |
| 缓存 | 3 | 4 | 基础回答未充分交代跨进程共享状态假设 |
| 配置 | 3 | 4 | 基础回答缺少启用/禁用时具体返回行为；检索回答的一项等价表达经裁决计分 |
| 文档权限 | 3 | 3 | 均未明确说明未展示令牌密码学验证与有效期检查 |
| 分片上传 | 2 | 3 | 基础遗漏已完成会话拒收分片；两者对完成幂等/并发保证等要求覆盖不全 |
| 任务租约 | 3 | 3 | 均未完整说明 ack/renew 的 done 条件与状态更新 |
| 账目导入 | 3 | 2 | 均遗漏额外列忽略；检索回答另漏其他异常类型不被捕获 |
| **合计** | **17/24（70.8%）** | **19/24（79.2%）** | |
| **每题平均** | **2.83/4** | **3.17/4** | |

检索工具可用组在三题高一分、一题低一分、两题持平。A 的原始总分是 17 对 18，B 是 17 对 19；多数裁决后的 17 对 19 差距只有两分，且其中一分涉及解释不确定性。

满分仅表示覆盖这四条标准，并不等于答案没有其他错误。两位评审另列了准确性问题，例如：

- 缓存基础回答把 TTL 推广为“有界最终一致性/30 单位自愈”，源码并不保证数据库新鲜性、共享状态和并发收敛。
- 缓存检索回答声称写失败后缓存仍与数据库一致、无需回滚；注入的 `db.write` 抛错并不能排除部分持久化副作用。
- 租约回答把某个并发领取者的 token 必然变旧当作通则；某些交错下两个调用都可能读取并返回相同的最终 token。

这些备注完整保留；没有在解盲后临时增设扣分规则。

## 唯一分歧与裁决

配置题检索组的第 4 条，A 给 0，B 给 1。A 认为没有清楚写出 `enabled=True` 的成功分支与返回值；B 认为答案的“先解析后传给 worker、worker 读取 enabled/attempts/timeout、禁用返回 False”已等价表达。

C 在不知道 A/B 分数与组别的条件下给 1，接受跨句描述的数据流含义，但明确标记中等不确定性。按预先固定的多数规则，最终记 1。若采用 A 的较严格解释，检索组为 18/24，基础组仍为 17/24。完整理由与源码证据见三份原始评分文件。

## 能说明什么、不能说明什么

本次真实运行的十二组都正常终答，评审也全部完成；这里的扣分属于内容覆盖或准确性问题，不是运行失败。此前自动定位召回 100% 不能替代内容评分。

**不能据此声称 LocAgent 带来质量提升。** 真实调用 LocAgent 的只有文档权限题，该题两组均为 3/4；其余分差出现在没有调用检索的题上。工具可用性本身改变提示上下文，再加上单次模型输出差异，无法从六题一次试跑中分离因果效应。

独立性和有效性的限制：

- 三位评审使用新上下文且不共享评分，但属于同一助手环境/模型家族，可能共享偏差；未做独立人类复核。
- 文件访问靠明确任务边界约束，不是操作系统级隔离；评审未读映射的证明主要来自分配上下文、访问范围和其声明，不能称强制信息隔离。
- 没有显式分组标签不代表无法从措辞、证据范围等线索推断组别。
- 二元复合标准对遗漏敏感，语义等价存在判断空间；保留全部理由、不确定性及分歧，不把一致率当正确性证明。
- 数据仍是自写开发集，作者看过源码与标准；缓存题此前参与调试，全部题目已有真实模型暴露。不是独立测试或泛化证据。
