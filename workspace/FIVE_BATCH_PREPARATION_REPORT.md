## 实现和硬限制

父授权绑定五题顺序、每题计划、代码及评分哈希、人民币单价确认和批次总额，24 小时内有效；一次性 claim 和独占运行目录阻止同一授权重复启动，无恢复/自动重试入口。每题开始前父账本占用 17 元，子账本请求前逐次预留；正常完成两组后才释放父占用并登记用量。任一异常停止批次，未知结算保留占用，后续题标记未启动。已完成结果不丢弃；过期后仍可只读审计账本，不能继续请求。

| 限制 | 固定上界 |
|---|---:|
| 开发题 / 系统数 | 5 / 2 |
| 每题每组 / 每题 / 全批请求数 | 4 / 8 / 40 |
| 每题 / 全批费用上限 | 17 / 85 元人民币 |
| 每组累计调查工具调用 | 16 |
| 每组累计证据 / 单页 UTF-8 字节 | 14,336 / 4,096 |
| 单次完整 JSON 请求 / 响应字节 | 65,536 / 65,536 |
| 单次输出 token | 2,048 |
| 总输出 token | 81,920 |
| 保守单次 / 合计输入 token | 1,048,576 / 41,943,040 |

按输入 2 元、输出 8 元/百万 token 的保守价格上限，每请求预留 2.113536 元，40 次全部预留为 **84.54144 元**。这是预算保护，不是预计费用。85 元上限以人民币有效价格及全部必付费用被覆盖为前提；本轮未联网核价，不能声称已确认当前账户计费。模拟账本的 0.112 元是脚本用量产生的测试数，实际花费为 0。

每题新子进程；两组有独立会话、工具预算和分页状态，原生组再使用独立引擎进程。组序 A/B、B/A、A/B、B/A、A/B。每次请求核验父批次活动状态；父进程丢失时停止。单题进程超时 720 秒后结束进程组，内部原生工作进程上限 300 秒；不补跑。第四次请求只开放 finish，或证据预算提前耗尽后收尾；正常空终答属于定位未命中。

## 数据隔离及离线证据

运行计划严格限定字段；加入 gold、reference_patch 或 semantic_review 等额外字段即拒绝。运行时仅由固定 source-only 入口取原题和源码；脚本检索查询来自原题第一行中的标识符，不用 gold 生成。评分绑定、完整补丁和语义审查仅由**模拟结束后的离线审计器**读取，不进入执行 worker。

逐一审计 40 个序列化请求：均包含本题原始全文，不含其他四题全文、完整参考补丁或评分目录；各组第一轮无旧 assistant/tool 历史；十组第四轮均只允许 finish。合法源码可能包含 gold 对应符号，所以没有把“出现目标函数名”误判为泄漏。此检查验证字段和数据流，不等于消除原题自带的位置提示。

| 系统 | 请求数 | 本轮最大完整请求字节 | 本轮最大累计证据字节 |
|---|---:|---:|---:|
| A 原生适配 | 20 | 28,245 | 12,288 |
| B OpenHands 适配 | 20 | 17,095 | 9,133 |

A 的脚本流程覆盖正文检索、证据分页/实体读取和 finish；B 覆盖列表、按行读取、实体检索和 finish。五个 SDK 会话 ID 各不相同，网络尝试记录为 0。**Mock 选择由脚本指定，不能当作模型自主选择检索或定位成功。** 模拟答案为空，评分聚合明确 `quality_scored=false`。
