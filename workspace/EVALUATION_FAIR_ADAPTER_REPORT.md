# 评测前共同约束与正文后端（2026-11-14）

本轮完成适配后的原生 LocAgent 与 OpenHands 的共同执行约束、正文检索接入、授权传输适配及离线验证。最新 SQLGlot 单题两组共 8 次模拟请求全部完成；真实模型请求、真实费用、对外传输均为 0。没有读取实际密钥或 .env，没有执行目标仓库代码，没有改写历史结果、v4 引擎或现有 readonly_agent harness。

这里的比较对象是**适配后的两个完整系统**。不是未修改的上游 LocAgent，也不能由它直接推出检索的因果收益。130 题正式有效性仍未完成：本轮语义抽查新增了标签覆盖和题意范围问题。

## 已实现的共同口径

| 项目 | 两组共同约束 |
|---|---|
| 模型/生成参数 | deepseek-flash；temperature=0；thinking disabled；每响应最多 2,048 输出 token |
| 请求 | 每组最多 4 次；最后一次只提供 finish，强制 finish tool_choice；可提前完成 |
| 调查工具调用 | 每组累计最多 16；超过剩余额度的整批响应拒绝执行 |
| 源码证据预算 | 每组 14,336 UTF-8 字节，包含模型可见工具内容的 JSON 包装 |
| 单页 | 最多 4,096 UTF-8 字节；重复页仍扣额度；游标为输出字符位置，不是源文件行号 |
| 请求/响应 | 精确序列化请求最多 65,536 字节；原始响应最多 65,536 字节 |
| 控制消息 | 工具关闭反馈另计至最多 4,096 字节；全部消息包装及提示仍受请求总字节限制 |
| 终答 | 相同 finish(message={files, entities, answer}) schema；files/entities 各最多 5；不截断有效回答 |
| 校验 | 两组共用格式、唯一性及源码路径校验；语法合法但不存在的符号属于定位错误，不借图成员关系作为一组独享的终答裁判 |
| 传输 | 共用请求构造、响应校验、持久化预算账本；先预留、后传输、保存原始回包、再结算；异常停止、不自动重试 |

实现位于 `experiments/eval_preflight/common_contract.py`、`native_adapter.py`、`sdk_adapter.py`。原生适配在独立 worker 内临时替换分页/收尾协议并在退出时恢复；SDK 适配从现有运行器复制，保留实际 SDK 循环。两边原有不同的请求体估算门槛已由共同的精确 wire 字节检查取代。跨轮重复 tool-call ID、超预算批次、未知工具、混合 finish、截断及超限输出均拒绝。

模型能看到的初始信息仍来自相同题面和同一个冻结源码快照；提示形式、工具表面、索引排序、源码呈现形式以及普通工具的错误行为仍属于系统差异。相同预算不意味着实际返回字节数、信息密度或定位能力相同。

## 正文检索后端

新增 `body_index.py`：仅从显式源码清单静态读取，以固定 80 行分块构建本地 BM25；记录文件路径、起止行和原始源码哈希。加载时核对整个索引文件哈希、快照及全部 corpus 文本/元数据。BOM、CRLF 和 Unicode 原文保留，不加载仓库模块。

已曝光 SQLGlot 3417 生成 1,005 个正文块。原生 `search_code_snippets` 的正文回退已真正接入此后端；模拟查询 `SET TAG` 来自题面，返回 10 个检索候选、选择 5 个供原生工具呈现，随后真实执行分页续读。实体 BM25 仍是独立索引，不冒充正文索引。

这是**固定行分块后端，不等同上游 EpicSplitter**。它覆盖当前 Python 源码快照，包括测试文件；原生工具既有关键词过滤、实体优先与图遍历行为仍保留。未宣称对原版分块、排序或完整非 Python 仓库信息等价。本轮只建并验收该开发题的正文索引，没有把 130 题全部重新索引。

## 授权与真实传输保护

新增 `live_guard.py` 的 ComparisonAuthority / SharedLiveWire，接入已有一次性票据传输实现。它要求新的比较专属授权类型、精确计划、适配代码哈希、v4 清单、新旧索引哈希及源码快照绑定；一般旧实验授权被拒绝。账户币种、单价上界、总上限、时效及一次性 claim 沿用现有门禁，每次传输前重新核验。

当前所有预备计划 `live_transport_enabled=False`，没有创建真实授权。契约中的 live_enabled=false 表示本轮预备/模拟状态。将来需在审查完比较定义后生成带明确 live 审查标记的新计划、重新冻结并批准，不能修改现有模拟计划冒充已获批准。

原生 provider 适配与 SDK 的真实传输代码路径已使用**人工凭据占位符、临时合成授权和模拟 HTTP helper**测试：helper 没有运行外部进程或联网，持久化票据逻辑保留；验证超时后不再启动第二个 helper，模拟凭据不落盘。该测试只验证连接与保护逻辑，不代表供应商协议、账户价格或真实服务可用性已验收。原生 worker 的当前命令行入口继续只允许模拟模式；尚未发布 130 题批量真实启动器。

## 模拟与回归结果

最新证据在 `verification/eval-fair-v3/`：

- 原生与 SDK 各 4 次模拟请求，均正常 finish；模型参数与最终提供的 finish schema 完全相同。
- 原生调查工具 3 次，实际提供 12,288 字节；SDK 调查工具 3 次，实际提供 1,481 字节。均低于共同上限；脚本动作不同，不能比较定位分数或成本收益。
- 原生工具进行了正文检索、一次 `read_tool_output` 续页及实体/文件读取；SDK 进行了普通搜索、按行读取和实体检索。
- 重复组启动被拒绝；源码、图、实体缓存和正文缓存均绑定哈希。模拟账本费用是测试数字，不是实际账单。
- 20 项评分/故障分类测试、25 项共同契约及授权传输测试、2 项正文索引测试、18 项既有预算故障回归通过，共 65 项。测试包含构造函数双向归一、归一后重复、类别实体保留、空终答、未知符号、截断/超时/未运行分类、累计额度、精确请求字节边界、重复 ID、Unicode 分页、索引篡改及旧授权拒绝。

本轮 v1、v2、v3 三次成对模拟产物全部保留，共 24 次成对集成脚本响应；单测中的人工响应另计。v3 是最新适配版本。v2 与 v3 留存精确适配源码副本；v1 用于初始连通性记录，不应与 v3 混报。模拟结果不参与定位评分。

## 剩余障碍与下一步

1. 比较定义需明确接受“固定行分块、共同预算的适配后完整系统”。如目标是复现原版 LocAgent，必须另行固定原版索引/工具协议并说明预算改动，不能使用本轮名称代替。
2. 正文后端及共同执行约束仅在 1 道已曝光真实开发题加人工边界样例验证；没有据此宣布 130 题全量共同入口通过。扩展前需逐题正文索引与范围绑定验收，以及批量中部分失败/恢复策略的独立门禁。
3. 两道新增语义暂停项、提示程度分层、第二评审及曝光来源尚需继续核验。当前不能给出“130 道有效独立评测题”的结论。
4. 小规模真实试跑仍可限定 SQLGlot 单题、两组最多共 8 请求、17 元总上限；仅发送题面、提示、工具定义、该组源码证据和会话，不含 gold、补丁或审查记录。17 元沿用历史单价保守预留，并非预估花费或当前报价。未查询当前账户价格，真实入口默认锁定；须在最终比较定义和计划冻结后再核价与取得新授权。

Python 网络防护不等于 OS 级沙箱。所有目标源码只被静态读取/解析；实际模型选择、定位正确率、费用和耗时收益均尚未测量。
