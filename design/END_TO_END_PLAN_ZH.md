# 端到端对照方案：设计冻结，未运行

## 主要问题与三组输入

主要对比为 C−B：改进定位能否提高相同 Coding Agent 的 resolve 率。A 为不提供定位输入；B 为当前 v6 标识符 BM25、源码预览和 v7 自检定位；C 为完整函数体 BM25 + 真实 dense cosine，按实体取最高 chunk 分，再以 RRF 常数 60、词法权重 1、dense 权重 2 融合，保留同名定义并选择匹配证据块。A/C、A/B 为次要对比。当前 B 的历史源码与 C 的新源码一并按哈希固定。

三组都用 OpenHands SDK 1.62.0 的同一 `Agent`、同一系统提示 `coding-system.txt`、同一 terminal/file_editor/finish 工具接口与基础提交。在独立容器中修复，可读、改源码并运行已有测试；不开放在线搜索或定位检索工具。SDK 只读工具接入已离线测试，**可写 Coding Agent 工具和云端执行驱动本轮只设计，尚未实现验证**。

编码输入固定为系统提示、原始题面、可为空的 `localization_packet`。A 传 null；B/C 都按 `packet-schema.json` 提供最多 5 个有序位置及原始行号源码片段，序列化总长不超过 14,336 UTF-8 字节。不得混入参考补丁、标准答案、推测的补丁代码或历史回答。包内不显示组别。候选行范围须属于基础提交且 start≤end，路径须在仓库内，所有片段核对原始源码。定位失败记技术失败，输入空包后继续编码（若属于请求异常则按全局停止规则停止）。定位省下的预算不转给 A。

## 评分规则

主指标为每组 `sum(resolved)/(50×3)`。resolved 仅取固定 SWE-bench 官方 harness 对 FAIL_TO_PASS 与 PASS_TO_PASS 的结果。基础镜像、环境镜像、实例镜像和执行环境须在正式运行前记录 digest；平台固定 Linux x86_64/amd64 云主机。Harness 固定提交 `02e7a74ffd0b707aab73d203fe87bdc7c76afc8e`。预测 JSONL 按官方字段 `instance_id/model_name_or_path/model_patch`，每组每次重复用独立 run_id，避免缓存混用。每次评测时限 1,800 秒。数据必须来自已经核验哈希的固定修订，不能默默读取最新 main。容器构建、测试和运行：**未运行**。

缺失、空补丁、模型故障、工具故障、超时以及评测错误在主指标中均记 0，单独拆出技术失败率。若异常导致中止，报告预定 150 分母与实际完成数、完整配对数，同时说明实验未完整执行，不能把剩余缺失当作可靠的效果证据。

次要指标只由隔离评分器在揭盲时计算：

- 文件 Recall@5：前 5 个去重文件覆盖参考补丁生产源码文件的比例；排除测试路径（任意 tests/test 目录、test_*.py、*_test.py）、文档与配置，只纳入 Python 生产文件。无符合标签的题记 NA 并报告数量，仍留在主指标分母。删除、重命名按基础提交旧路径；仅新增文件没有旧源码位置，记不可定位 NA，不能当命中。
- 函数 Recall@5：参考补丁在基础提交上的删除/修改行，与 Python AST 函数跨度相交的实体集合为标签；仅新增行以 diff 旧侧锚点为近似位置，标记锚点标签，另报排除此类标签的敏感性。采用 `path:QualifiedName` 去重；重复定义可归同一实体，证据覆盖按实际 span 区分。无可映射函数记 NA。前 5 个位置为空时，在有标签题上为 0。
- A 没有定位输出，定位 Recall@5 报 NA，不把它的源码搜索轨迹事后变成另一个定位算法。B/C 定位包按实际交付顺序评分，不能从日志挑最优候选。
- 证据覆盖：实际交付编码 Agent 的定位包行区间，与上述有标签的旧源码变更行相交的比例；纯新增文件/无旧侧变更行记 NA，新增锚点另报。它是参考补丁行覆盖代理指标，不声称证明因果或覆盖唯一正确修复。
- 技术失败分型：定位、模型/网络、预算/超时、编码工具、镜像构建、评测器；每个试验保留完整状态链。
- 成本：实际 usage、缓存命中、请求数、embedding、云主机与磁盘单独记账；共享索引构建成本同时报总额及按 C 组试验摊销值。记录端到端耗时，不把定位费用藏到外部。

## 配对统计

每题先对三个二元 resolve 结果求均值，再计算各组之间的逐题差；50 题是配对统计单位，不把 450 次试验当成 450 个独立样本。报告百分点差及 95% 按仓库分层的配对题目 bootstrap 区间（20,000 次，seed=20261116）；仓库只有一题的层不能提供层内变异，明确这属于固定题集不确定性估计。

显著性采用题目为簇的双侧配对符号翻转检验（100,000 次 Monte Carlo，seed=20261116，加一修正）；C−B 是主对比，三项对比统一 Holm 校正、alpha=.05。敏感性用预先指定的第一次重复做精确 McNemar，报告不一致对数量。不得以 best-of-three 或 pass@3 替代主要 resolve 率。`scripts/paired_statistics.py` 仅用合成数据完成自检。50 题难以证明小幅改进；区间宽或不显著时结论为证据不足，而不是“没有效果”。
